# Paperclip-AI
This repo is how I setup Paperclip AI in my home environment to create a home SOC


Paperclip AI is a 

Since I have a Proxmox server, I used this link found [here](https://community-scripts.org/scripts/paperclip?from=scripts&fromQ=Paperclip+ai) that allowed me to create a LXC



Paperclip AI finished setup:

<img width="1027" height="935" alt="image" src="https://github.com/user-attachments/assets/bc6f00fb-d064-4d31-91c4-66d6ee758eae" />


You take the link that the script gives you at the end and put it in your browser to register. Youre results should look like this

<img width="1696" height="800" alt="image" src="https://github.com/user-attachments/assets/2a9812e8-c745-451c-a0f5-2d70edc78f2f" />

Once you are here, simply create a new account. Once you have created the account, you will be promoted with naming your organization. Simply fill this part out and move on.


<img width="891" height="666" alt="image" src="https://github.com/user-attachments/assets/6f80ad66-cc72-4200-a2ee-75812658f6cb" />


Next, you want to name the first agent you create. Since this is to mock a real life enterprise, we will call this agent "CEO" and then click next. 

<img width="799" height="636" alt="image" src="https://github.com/user-attachments/assets/b487541b-17a1-44ea-8b92-36316bfbeb51" />

Next, you will be prompted to connect any AI models that you have. Since I have Claude, I will link my account to Paperclip ai. 

<img width="862" height="734" alt="image" src="https://github.com/user-attachments/assets/d55ae61e-0132-4e6e-9df6-d48303402dd2" />


Follow the instructions from the output. Navigate to the VM you create and paste the command into your terminal/shell

<img width="900" height="858" alt="image" src="https://github.com/user-attachments/assets/79e45558-222d-4277-852b-1658e31cf0c7" />


Once you paste it, you will get a link from the output to navigate to, to sign in with your Claude account. Please note you will need the Max level subscription for this to work. Once you authenticate, you will get a code to put back into your terminal in the VM that has paperclip ai. Once done, you will see Login Successful for the output. 


Heading back over to the Paperclip Web UI, we can see that we can now move on to the next step


<img width="806" height="664" alt="image" src="https://github.com/user-attachments/assets/e6b6c155-0da6-4d85-a374-f81bd579b90b" />

<img width="1890" height="932" alt="image" src="https://github.com/user-attachments/assets/1a8dd014-ba80-4e0b-8879-7e1771f60b7f" />
